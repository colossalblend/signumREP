# Обновления компонентов Signum

Содержимое этой папки разворачивается на API-сервере в `signum/files/tools/`, а endpoint `tools.php` остаётся в `signum/`. Клиент получает только манифест для своей платформы, скачивает файл по адресу из манифеста через закреплённое HTTPS-соединение и до замены проверяет **размер** и **SHA-256**. Если проверка или загрузка не проходит, приложение продолжает использовать последнюю проверенную либо встроенную версию.

| Платформа | Обязательные компоненты из текущей поставки | Дополнительный компонент |
|---|---|---|
| Windows x64 | `ipatool-v2`, `ipatool-v3`, `anisette` | — |
| macOS x64 / Apple Silicon | `ipatool-v2`, `ipatool-v3` | `anisette`, если предоставлен совместимый бинарный файл |
| Linux x64 / ARM64 | `ipatool-v2` | `anisette`, если предоставлен совместимый бинарный файл |

Для подготовки релиза из корня репозитория выполните PowerShell-команду. Она очищает старые файлы в `backend/signum/files/tools/<платформа>`, копирует текущие бинарные файлы, вычисляет контрольные суммы и создаёт `manifest.json`.

```powershell
.\scripts\publish_tools_release.ps1 -IpatoolVersion 3.9.9.3
```

Если появились нативные сборки anisette для macOS или Linux, передайте пути к ним. Они будут добавлены в соответствующие разделы манифеста и начнут автоматически обновляться на этих платформах.

```powershell
.\scripts\publish_tools_release.ps1 `
  -IpatoolVersion 3.9.9.3 `
  -AnisetteVersion 3.0.1 `
  -MacOsAnisetteX64 C:\release\macos-x64\anisette `
  -MacOsAnisetteArm64 C:\release\macos-arm64\anisette `
  -LinuxAnisetteX64 C:\release\linux-x64\anisette `
  -LinuxAnisetteArm64 C:\release\linux-arm64\anisette
```

После запуска скрипта разверните на сервере **всю** папку `backend/signum`, включая `tools.php`, `files/tools/manifest.json` и подкаталоги с бинарными файлами. Веб-серверу требуется только право на чтение файлов. Не меняйте бинарные файлы вручную после генерации манифеста: `tools.php` сверяет их размер и SHA-256 с манифестом и исключает изменённый файл из ответа.

> `anisette` для macOS и Linux будет доставляться только после публикации совместимого нативного бинарного файла. Текущий репозиторий содержит `anisette.exe` только для Windows; скрипт не маскирует отсутствие неподдерживаемого файла.
