# Запуск Signum

Рабочий экземпляр перенесён на VPS в `/opt/signum-bot`. Бот, API и мост
работают через `signum-bot.service` и `signum-api.service`. Они включены
в автозапуск systemd; `signum-health.timer` проверяет состояние каждую минуту.
Локальные процессы Windows остановлены, задача `SignumProduction` отключена.
Для управления на VPS:

```bash
systemctl status signum-bot signum-api
systemctl restart signum-bot signum-api
journalctl -u signum-bot -u signum-api -f
```

Публичная панель: https://signum.appbank.pw/api/panel.
Документация: https://signum.appbank.pw/api/docs.
Сайт и файлы обслуживаются хостингом, запросы API передаются на VPS через
подписанный зашифрованный мост. Файлы передаются на хостинг частями по HTTPS
с проверкой подписи запросов, порядка частей, размера и SHA-256; удаление
проходит через тот же защищённый канал. На VPS установлен
`BRIDGE_FILE_TRANSPORT=https`. FTPS остаётся для публикации PHP и страниц.
Публичный HTTPS проверен с доверенным сертификатом.
Apple-сессия повторно зашифрована для Linux; Telegram-сессии перенесены.

После передачи файла с iPhone бот задаёт вопрос об установке. Подтверждение
«Да» удаляет IPA и отключает его ссылки. Определение устройства основано
на запросах страницы, манифеста и файла; результат установки подтверждает
владелец в Telegram. Проблемы установки отправляются администраторам.

## Локальный резервный запуск

Бот и API запускаются вместе с контролем процессов:

```powershell
cd /d D:\Signum-v1\bot
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_production.ps1 -Restart -InstallAutostart
```

В PowerShell вместо `cd /d` используйте `Set-Location D:\Signum-v1\bot`.
Автозапуск срабатывает при входе в текущий Windows-аккаунт. Компьютер должен
оставаться включённым. Контроль процессов проверяет состояние бота и API и
перезапускает их при остановке или зависании.

Локальная панель: http://127.0.0.1:8088/api/panel.
Не запускайте локальный экземпляр одновременно с серверным: оба используют
один токен бота и одни Telegram-сессии. Перед резервным запуском остановите
службы Signum на VPS и перенесите актуальную базу и сессии с сервера.

ЮKassa настроена на боевой магазин. Демо-покупки отключены для обычных
пользователей. Подписки и разовые скачивания оплачиваются в рублях. Оплата
зачисляется после проверки суммы, валюты, магазина и статуса через API ЮKassa;
уведомление само по себе не активирует покупку. Проверка статуса предусмотрена
в боте и панели, ожидающие оплаты также проверяются в фоне.
Документация: https://yookassa.ru/developers/using-api/interaction-format.

В админ-панели доступны отдельные техработы бота и API, состояние сервисов,
последние оплаты, общие Apple ID, зашифрованная резервная копия и управление
ключами. Подтверждение существующих оплат продолжает работать во время
техработ. Администратор сохраняет доступ к панели.

Бесплатные ссылки доступны один час, платные и API — двенадцать часов.
Удаление просроченных файлов проверяется каждую минуту. Уже отправленный в
Telegram файл удаляется с локального диска сразу после отправки.
Незавершённые загрузки удаляются при завершении или отмене задания.

Бесплатный лимит общий для Telegram-аккаунтов с подтверждённым общим Apple ID.
Учитываются также связанные аккаунты и загрузки в работе. Сессии разных
владельцев сохраняются отдельно; почта не позволяет забрать чужую сессию.
Apple ID и задания API доступны только владельцу и ключу, который их создал.
Для выбора сохранённого Apple ID используется `account_id` и тот же ключ.
Это не перенос аккаунта на другой ключ и не повторная авторизация в Apple.
Активные аккаунты API прогреваются каждые двенадцать часов; при паузе или
отзыве ключа, блокировке клиента или окончании API прогрев прекращается.

Логи находятся в `data/logs`: размер каждого основного журнала ограничен
5 МБ, сохраняются три предыдущих файла. Пароли и ключи не выводятся при
ошибках. Резервные копии создаются каждые шесть часов в `data/backups`;
хранятся последние 28 файлов. Для восстановления требуется отдельно
сохранить `data/secrets/apple-api.key`. Потеря этого ключа сделает резервные
копии и сохранённые пароли API нечитаемыми.

Основные зависимости зафиксированы в `requirements.txt` на проверенных
версиях. Проверки запуска:

```powershell
python -m ruff check signum_bot tests
python -m unittest discover -s tests -p "test_*.py" -q
python tests/test_bot.py
```
