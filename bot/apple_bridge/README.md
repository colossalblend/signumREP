# Apple для Signum Bot

Нативный помощник использует модули `apple_history.rs` и `apple_region.rs`
из Signum. Копии исходников находятся в `src/vendor`. HTTP-диагностика отключена:
ответы Apple, пароли, коды и cookies не записываются в логи.

Сборка:

```powershell
cargo build --release --locked --manifest-path apple_bridge/Cargo.toml
Copy-Item apple_bridge/target/release/signum-apple-bridge.exe bin/signum-apple-bridge.exe
```

На Linux/macOS бинарник без `.exe`. Можно задать `APPLE_BRIDGE` абсолютным путём.
Переносить нужно только бинарник: Rust и исходники для запуска не требуются.
`Cargo.lock` фиксирует версии зависимостей.

Обновление копий из соседнего Signum: `python tools/sync_apple_bridge.py`.
После синхронизации повторите сборку и `cargo test --release --locked`.

Помощник общается с ботом JSON через stdin/stdout. Пароли не передаются в аргументах
процесса. Один процесс обслуживает только один Apple ID; состояние подтверждения
2FA сохраняется в памяти на время запроса. В боте сессии и кеш покупок зашифрованы
тем же локальным хранилищем ключей, что используется для API.

История: до восьми приложений на странице, кеш на час, ручное обновление, переход
к карточке для скачивания IPA или установки. Следующие партии запрашиваются по
курсору Apple; короткие партии не пропускают приложения. Внутри одного запроса
читается до пяти партий, после чего доступна кнопка продолжения.

Смена страны: список поддерживаемых стран и адресов из Signum, просмотр адреса,
ввод своего адреса и отдельное подтверждение. Код нужен только при запросе Apple.
Подтверждение и код привязаны к текущему владельцу, аккаунту и операции, срок —
10 минут. После трёх непринятых кодов запрос отменяется. Изменённая страна
отображается в карточке Apple ID; кеш покупок и проверки лицензий обновляется.

Баланс и действующие подписки могут препятствовать смене страны. Бот показывает
понятную причину и ссылку на настройки Apple. Предусловия описаны в
[инструкции Apple](https://support.apple.com/118283).
