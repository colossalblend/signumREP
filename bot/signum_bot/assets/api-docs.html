Подключение за три шага

API оплачивается отдельно от подписки бота.

Подключите Apple IDВ панели API укажите почту и пароль. Код понадобится только при запросе Apple.
Активируйте пакет APIОткройте /api и выберите «Подключить». Оплата проходит через ЮKassa. Тестовый режим отмечается на экране оплаты.
Создайте ключОткройте «Мои ключи» в боте или создайте клиента из терминала администратора. Сохраните ключ и передавайте его в заголовке Authorization. Подойдёт Python, JavaScript или любой HTTP-клиент.
Ваш первый запрос


Каждый Apple ID доступен только с ключом, который его подключил. Аккаунты и задания другого ключа недоступны даже при известном ID. Сессия обновляется каждые 12 часов, пока API и ключ активны.
Вход в Apple ID без бота
Сохраните account_id из статуса ready. Передавайте его в POST /downloads для IPA или установки на iPhone. GET /accounts/{account_id} возвращает состояние аккаунта. POST /accounts/{account_id}/restore выбирает сохранённый аккаунт без повторного ввода пароля — только с первоначальным API-ключом.
POST /auth/jobs запускает вход и сразу возвращает job_id. GET /auth/jobs/{job_id} показывает статус. Почта и пароль передаются в JSON, а не в адресе.

При ready вход завершён — код вводить не нужно. При requires_2fa отправьте POST /auth/jobs/{job_id}/code с code и challenge_token. Используйте тот же API-ключ. Задача действует 10 минут, не более трёх отправок кода.
Можно подключить несколько аккаунтов. Список — GET /accounts. При загрузке передавайте account_id; с несколькими готовыми аккаунтами выбор обязателен. Пароли шифруются, код 2FA не записывается в базу.

1. Создать загрузку · POST /downloads
2. Пример готового ответа · GET /downloads/{job_id}
Повторный запрос с тем же Idempotency-Key возвращает ту же задачу. При ошибке лимит загрузок возвращается. Проверяйте статус раз в 5 секунд. Примеры здесь генерируют код, а не запускают скачивание.

Нужно больше загрузок?
В пакете API — 1000 загрузок на 30 дней. Общий объём скачанных файлов не ограничен; одно приложение — до 4 ГБ.
Дополнительные загрузки не продлевают API. Их остаток сохраняется для следующего периода. Сначала расходуются загрузки основного пакета. Для использования нужен действующий доступ к API.
Пополнить баланс · POST /billing/orders
Ответ содержит order_id и payment_url. Откройте payment_url для оплаты, затем проверьте GET /billing/orders/{order_id}. Начисление выполняется только после проверки платежа на сервере ЮKassa. Повтор с тем же Idempotency-Key возвращает прежний заказ.
Доступ под вашим контролем
Пароль Apple ID остаётся на стороне бота и не попадает в ответы API.
Ключ с ограниченным сроком
Секрет создаётся из 32 случайных байт. В базе хранится его хеш. Каждый ключ имеет своё имя, срок и квоту. Его можно приостановить или отозвать. Создание нового ключа сохраняет остальные.
Отдельный ключ для чтения
Можно разрешить только чтение каталога, версий и своих задач. Такой ключ не создаёт и не отменяет загрузки, не оформляет покупки. Полный ключ имеет права read, downloads, accounts, billing и keys.
Защита от перегрузки
Приватные задачи и ссылки
Задачи доступны только владельцу. Ссылки используют случайные токены и истекают; DELETE /downloads/{job_id} отменяет задачу или отзывает готовую ссылку.
Используйте ключ на своём сервере, не в публичном коде сайта. Для внешних запросов требуется HTTPS. Ключ не передаётся в адресной строке.


Проверить свой доступ
Выполняется только GET /me. Загрузки не создаются и лимит скачиваний не расходуется.
Ключ остаётся только в памяти этой страницы: не записывается в localStorage и не отправляется сторонним сервисам. После проверки поле очищается.
Ответ API


Если запрос не прошёл
401Ключ неверный, отозван или истёк. Создайте новый в боте.
403Закончился доступ к API, аккаунт заблокирован или ключу не хватает прав.
409Подключите Apple ID, дождитесь текущей загрузки или используйте новый Idempotency-Key для другой задачи.
422Проверьте ID приложения, формат JSON и Idempotency-Key.
426Отправляйте внешний запрос по HTTPS.
429Превышен лимит запросов или количества загрузок. Учитывайте Retry-After.
503Очередь заполнена или сервис временно недоступен. Повторите позднее.
